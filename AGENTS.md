# Course website instructions

Follow the assignment publishing standard in [README.md](README.md) when creating or revising homework, practice packet, or exam pages.

The default student experience is a course-styled landing page, a copy-opening button for editable student work, an embedded preview, and a verified Canvas submission link where applicable. Use the shared templates so future assignments inherit this behavior. Notebook preview assets and new Canvas assignment URLs still need to be configured for each release.

Do not release exam documents or solutions before the instructor authorizes them. Do not change source-document sharing permissions just to make a preview work.
